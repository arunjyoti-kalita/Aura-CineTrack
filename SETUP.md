

# ⚙️ CineTrack — Local Setup Guide

## Prerequisites

Before running CineTrack locally, install:

- Node.js
- npm
- Git

---

# Clone Repository

```bash
git clone https://github.com/arun-kalita/cinetrack.git
cd ct
```

---

# Install Dependencies

```bash
npm install
```

---

# Start Development Server

```bash
npm run dev
```

The application will run locally at:

```text
http://localhost:5173
```

---

# Build Production Version

```bash
npm run build
```

---

# Deployment

CineTrack is deployed using Vercel.

Production deployment automatically updates on push.
